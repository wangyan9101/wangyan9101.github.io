# 简历 V2

独立地址：`/resume-v2/`。第一版首页及其资源保持原样，无新依赖、无后端、无构建步骤。未执行 commit、push 或部署。

## 文件与结构

- `index.html`：静态项目详情（无 JavaScript 也可阅读与展开）、首屏、职业时间线、六类技能、三段工作经历、项目区、三张讨论型架构图、教育、联系。
- `content.js`：八个项目的事实内容、职责边界、技术难点、实现与待确认成果。
- `main.js`：项目渲染、分类筛选、详情、滚动导航、主题偏好、打印展开与状态恢复、数学线框生成。
- `styles.css`：独立作用域页面样式、响应式断点、深浅色、减少动态效果与 A4 打印样式。
- `mark.svg`：本站本地矢量图标。

使用系统字体与本地资源，不需要 CDN。所有页面资源使用相对路径，因此同时适用于用户站点和带仓库前缀的项目站点。博客入口 `../` 指向部署站点首页。

## 本地预览

在仓库根目录执行：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

打开 http://127.0.0.1:4173/resume-v2/ 。不要只预览根首页。停止服务使用 Ctrl+C。

## 使用与打印

- 导航可跳转并随滚动更新；键盘可操作筛选与原生 details。
- 项目支持 Graphics、Editor、Geometry、Digital Twin 多标签筛选。
- 深浅色默认跟随系统，手动选择保存在浏览器本地；存储不可用时仍能切换。
- 打印按钮调用浏览器打印，选择“另存为 PDF”。打印会展开并包含全部八个项目，忽略当前筛选；关闭打印后恢复原状态。长篇项目详情用于技术交流，因此 PDF 为多页版本。
- 架构图为能力讨论模型，不是原公司的内部架构。
